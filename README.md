# 三角洲口琴自动演奏器 🎵

一个用于《三角洲行动》游戏的口琴自动演奏 Web 应用，可根据口琴谱自动模拟按键操作。

## 功能特性

- ✅ **自动演奏** — 根据口琴谱自动模拟演奏
- ✅ **升降调支持** — 自动处理♯升调、♭降调、半音切换
- ✅ **口琴谱解析** — 支持文本输入和文件上传
- ✅ **实时预览** — 可视化口琴界面，实时高亮当前音符
- ✅ **速度控制** — 可调节演奏速度和变调切换延时
- ✅ **循环演奏** — 支持设置重复次数
- ✅ **暂停/继续** — 演奏过程中可以随时暂停
- ✅ **音符序列** — 显示解析后的完整音符列表

## 符号说明

| 符号 | 含义 |
|------|------|
| `1-7` | 自然音（do re mi fa sol la si） |
| `i` | 高音1（do·） |
| `#` 前缀 | 升调（如 `#1`） |
| `b` 前缀 | 降调（如 `b3`） |
| `.` 后缀 | 低音点（如 `1.`） |
| `_` 或 `-` | 休止符/停顿 |

## 快速开始

### 本地运行

```bash
# 克隆仓库
git clone https://github.com/PU12138/sjzkq.git
cd sjzkq

# 启动本地服务器（Python 3）
python3 -m http.server 8080

# 浏览器访问
# http://localhost:8080
```

### 直接打开

也可以直接双击 `index.html` 在浏览器中运行。

## 使用流程

1. **输入口琴谱** — 在文本框输入或上传 `.txt` 文件
2. **点击「解析谱子」** — 查看解析后的音符序列
3. **设置参数** — 调整演奏速度、循环次数等
4. **点击「开始演奏」** — 应用将自动按谱演奏
