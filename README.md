# 三角洲行动 · 口琴自动演奏器 🎵

在手机上自动按口琴谱演奏，支持**升调/降调/低音点**自动切换。

## 📱 核心文件

| 文件 | 用途 | 平台 |
|------|------|------|
| `auto.js` | **主程序**：Auto.js 自动化脚本，在手机上运行，直接点击游戏内按钮 | 安卓手机 |
| `index.html` | 辅助工具：在手机/电脑浏览器里编辑、预览口琴谱 | 任意浏览器 |
| `style.css` | Web 样式 | - |
| `app.js` | Web 谱子解析器 | - |

**👉 你主要需要的是 `auto.js` 这一个文件！**

---

## 🚀 快速开始 (3 步)

### 第 1 步：安装 Auto.js

在你的安卓手机应用商店搜索 **"Auto.js"** 或 **"Hamibot"** 下载安装（免费版即可）。

### 第 2 步：导入脚本

**方法 A — 手机直接下载：**
在手机浏览器打开本仓库 Releases（或 GitHub 首页），下载 `auto.js` 文件。

**方法 B — 电脑传文件：**
1. 电脑访问 https://github.com/PU12138/sjzkq
2. 下载 ZIP 解压，拿到 `auto.js`
3. 用微信/QQ 文件传输传到手机
4. 在 Auto.js 里点「导入脚本」选择该文件

**方法 C — 直接复制：**
打开 `auto.js` 文件内容，全选复制，在 Auto.js 新建脚本粘贴保存。

### 第 3 步：授权并运行

1. 打开 Auto.js，点击右上角设置
2. 开启 ✅ **无障碍服务**（系统设置里授权）
3. 开启 ✅ **悬浮窗权限**
4. 回到 Auto.js 首页，点击导入的 `auto.js` 运行
5. 首次使用建议先点 **"📍 坐标标定"** 校准一下（不同手机分辨率可能有偏差）

完成！

## 🎮 游戏内使用流程

```
Auto.js 运行 auto.js 脚本
        │
        ├─ 输入/选择口琴谱
        ├─ 调速度 (默认 400ms/音符)
        ├─ 点 ▶ 开始演奏
        │
        └─ 脚本弹出悬浮窗
               │
               └─ 3秒内切换到三角洲游戏
                     │
                     └─ 打开口琴演奏界面，横屏
                           │
                           └─ 悬浮窗点 "▶ 演奏" → 自动点按！
```

演奏过程中可以：
- 点悬浮窗 **⏸ 暂停**
- 点悬浮窗 **⏹ 停止**
- 演奏结束悬浮窗可关闭

## 📝 口琴谱语法

| 符号 | 含义 | 示例 |
|------|------|------|
| `1` `2` `3` `4` `5` `6` `7` | 自然音（do re mi fa sol la si） | `1 2 3` |
| `i` | 高音 1（do·） | `i 7 6` |
| `#` 前缀 | **升调** | `#1` → 自动切到升调模式再按 1 |
| `b` 前缀 | **降调** | `b3` → 自动切到降调模式再按 3 |
| `.` 后缀 | **低音点** | `5.` → 自动开关低音点再按 5 |
| `_` 或 `-` | 休止停顿 | `1 - 2` 中间停顿一拍 |

### 示例谱

**小星星**
```
1 1 5 5 6 6 5 - 4 4 3 3 2 2 1 -
```

**欢乐颂**
```
3 3 4 5 5 4 3 2 1 1 2 3 3 2 2 -
```

**含升降调**
```
#1 #2 #3 #4 #5 - b3 b6 b7 - 1. 2. 3. 4. 5.
```

## 📍 坐标标定 (重要!)

不同手机分辨率、游戏界面位置不同，**首次使用务必标定**：

1. 在 Auto.js 脚本主界面点 **🎯 开始标定**
2. 选要标定的按钮组（建议选"全部重新标定"）
3. 3 秒内切换到三角洲游戏，**横屏**打开口琴自动演奏界面
4. 屏幕上会出现**半透明绿色覆盖层 + 红色标记点**
5. **拖动红色标记点**对齐到游戏里对应按钮的中心
6. 对齐后点右下角 **✓ 确认位置**
7. 所有按钮标定完自动保存

> 💡 标定数据自动存在 Auto.js 本地，下次运行自动加载。
> 如果发现点偏了，重新标定即可。

## ⚠️ 常见问题

**Q: 点击位置不准？**
A: 重新标定坐标。确认游戏横屏状态下标定。

**Q: 脚本报错 "无障碍服务未开启"？**
A: 手机设置 → 应用管理 → Auto.js → 权限 → 无障碍 → 开启。

**Q: 点击没反应？**
A: 检查是否游戏前台、是否横屏、是否口琴演奏界面打开。

**Q: 想改速度/循环次数？**
A: Auto.js 脚本主界面的参数输入框直接改，演奏自动生效。

**Q: 谱子里想加高音点？**
A: 当前版本高音点用低音点按钮代替。如果你游戏里有独立高音点按钮，可在 auto.js 的 `DEFAULT_COORDS.pointHigh` 加一组坐标（后续版本会支持）。

## 🛠️ 关于 Web 版 (index.html)

Web 版是**谱子编辑器辅助工具**，不能直接在游戏里点按（浏览器安全限制）。

**Web 版用途：**
- 用手机/电脑浏览器方便地**写谱子、预览解析结果**
- 把谱子复制粘贴回 Auto.js 脚本输入框

本地运行：
```bash
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```
